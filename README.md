# BANANA BREAK — Jungle Rush

Godot 4 + GDScriptで作った、地形破壊とバナナ収集が中心の3Dアクション試作です。キャラクター、島、音はすべてコードで生成するオリジナル素材です。任天堂の公式作品や、その素材を使用した再現版ではありません。

## 起動

1. Godot 4.3以降で `project.godot` をインポートします。
2. **F6ではなくF5**でプロジェクトを実行します。
3. 岩を壊し、バナナを30本集めるとクリアです。

この環境では `C:\Tools\Godot\Godot_v4.7.2-stable_win64.exe --path C:\Users\onego\games\bananza-gpt` でも起動できます。

## 操作

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印 |
| カメラ | マウス / Q・C |
| ジャンプ | Space |
| パンチ | 左クリック / J |
| 空中からの叩きつけ | 空中でE |
| ダッシュ | Shift |
| マウス捕捉切り替え | Esc |
| やり直し | R |

パンチはキャラクターが向いている方向に当たります。ジャンプしてEを押すと、着地時に広い範囲のブロックを壊せます。岩の中のバナナは近づくと吸い寄せられます。赤い敵もパンチで倒せて、バナナを落とします。落下や敵への接触でエネルギーが減り、0になるとゲームオーバーです。

## 実装

- `scripts/player.gd`：CharacterBody3D、移動、ジャンプ、攻撃、SpringArm3Dカメラ、手続き生成キャラクター。
- `scripts/world.gd`：固定シードの破壊可能地形、バナナ、敵、破片演出、合成効果音、HUD、勝敗。
- 外部アセット、アドオン、ネットワーク接続は不要です。
- 小規模な1ステージの試作です。セーブ、ゲームパッド、製品版相当のボクセル地形処理は含みません。
