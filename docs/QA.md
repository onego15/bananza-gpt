# UNDERBLOOM 検証・制作記録

## 検証環境と方法

- Windows、Node.js 22.17.1、既存のGoogle Chrome、Playwright 1.51.1。
- 通常操作のブラウザテストは専用の空プロファイル、1280×800、DPR 1、ヘッドレスChromeで実行。ユーザーの普段のブラウザデータは使いません。
- 高画質設定：アンチエイリアス、影、ブルーム、ポストプロセス有効。
- 正確なGPU名、Chromeのリリース番号、他端末での性能は未確認。下記FPSはこの環境だけの実測です。
- インラインブラウザの観察ツールはURLポリシーにより使用できませんでした。ユーザーのタブへの迂回接続はせず、プロジェクト専用の独立したChromeテストで検証しました。

## 性能の実測

250件の球形CSGを適用し、再メッシュ完了後、翠緑のゆりかごを見渡すカメラで179フレームの実際の `requestAnimationFrame` 間隔を計測しました。

| 指標 | 実測 |
| --- | --- |
| 初回の平均FPS | **85.35 fps** |
| 初回の95パーセンタイルのフレーム間隔 | **14.10 ms** |
| 掘削で取り除いた密度サンプル | 10,258 |
| 保存された編集履歴（先行テスト分を含む） | 257件 |
| 計測終了時の未再生成チャンク | 0 |

これは「再メッシュ後の固定したカメラでの描画」の測定です。250件すべてに破片・粉塵を同時に発生させる測定でも、全プレイ時間の最低FPS保証でもありません。編集を一度に適用する瞬間や大きなエフェクトには一時的なフレーム低下があります。軽量画質モードを用意しています。

基壇保護を含む最後の再試験では、平均 **27.16 fps**、95パーセンタイル **55.60 ms** でした。同じ環境でも負荷変動が大きく、常時60fpsは未達です。初回の高い数値だけを性能保証として扱わないでください。最新の帰還・保存・秘密回収テストも成功しています。

初回ログ：[qa-stress.json](qa-stress.json)。最新ログ：[qa-stress-latest.json](qa-stress-latest.json)。テストには検査開始位置への配置、密度の検査、250件の直接CSG編集というQA専用操作を使います。トンネル通過・床掘り・宝箱回収・UI確認は実際のキー入力です。

## 発見と修正の経緯

1. 最初のスクリーンショットで、地形の単調さ・植物の偏り・カメラの接近過多を確認。
2. 封鎖壁の通常操作で、穴の入口の下端に停止することを確認。掘削を入口から奥まで連続させ、通常攻撃での床の低下を抑制。
3. 狭い穴でカメラが主人公の中へ入る画像を確認。最短追従距離、地形の局所切り欠き、プロップ遮蔽を追加。
4. 地形を0.75間隔へ細分化。岩肌・地層・植生・鍾乳石・ベベル・素材粒子・攻撃軌跡を追加。実画面を再撮影して確認。
5. 二度目の保存で古いCSG履歴が失われる問題を修正。二度連続の再読込テストを追加。
6. 最終床掘りで、表示上は穴でも古い床の近くに接地が残る問題を発見。CSG密度を正確な距離と扱う中心点判定から、**カプセル表面42点の実体判定**に変更。床を削った後に落下する回帰テストを追加。
7. 床Eの長押しから意図せず空中叩きつけへ移る動作を変更。空中叩きつけは空中でEを新たに押した場合に限定。
8. 通常のキー操作での通し進行、秘密の地下室、大量編集、保存のテストを繰り返した後、映像を更新。

## 確認していない項目

- 人間の初見プレイヤーによる15〜30分という所要時間、幅広いユーザーテスト。
- 商業インディー作品と同等の総合品質、長期間のプレイ耐久、すべての掘削形状の進行保証。
- タッチ操作・ゲームパッド・スマートフォン・Safari・Firefox・低性能GPUでの動作。
- 実スピーカー・ヘッドホンでの聴感評価。音源合成コードとブラウザでの開始処理は実行していますが、映像は無音です。
- 任意に増え続ける巨大な保存データに対する容量限界。保存失敗はUIで通知します。

## 最終通し確認

**PASS**。通常のキーボード操作だけで、最初の発掘 → 壁の掘削・通過 → 二つの鳴石 → 二つ目の灯種 → 神殿 → 守護者 → 三つ目の灯種 → 祭壇 → エンディングに到達。進行状態を直接書き換えたり、進行用のテレポートを使ったりしていません。

最終記録：灯種 **3/3**、鳴石 **2/2**、守護者撃破、endingSeen=true。ゲーム内経過 **51.40秒**、掘削履歴 **45件**。座標を知る自動操作による最短経路なので、初見の所要時間の検証ではありません。

再読込後も灯種・鳴石・守護者・エンディング・掘削履歴を保持し、JavaScript実行エラー **0件**。

## 高画質と軽量画質の比較

同じ掘削済み洞窟で、実際のEscメニューから画質を切り替え、各119フレームの間隔を測りました。

| 設定 | 平均FPS | p95フレーム間隔 |
| --- | --- | --- |
| 高画質 | 26.90 | 48.60 ms |
| 軽量 | 34.00 | 41.70 ms |

軽量設定で改善しましたが、この比較でも60fpsには届いていません。影・ブルームの負荷だけでなく、地形と多数の装飾・キャラクターの描画コール数も制約です。
